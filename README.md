## Getting Started

Website Link: https://pathwayprodigy.in/

Overview
This project showcases a modern and responsive portfolio website designed specifically for an Education Consultant. Built using Next.js, the website integrates seamlessly with the Formspree API to handle form submissions efficiently. The goal is to provide a user-friendly interface that highlights services and expertise while ensuring optimal performance and accessibility across devices.

Features
1. Next.js Framework: Utilized Next.js for server-side rendering, enhancing SEO and performance.
2. Formspree Integration: Integrated Formspree API to manage contact form submissions securely.
3. Responsive Design: Designed a responsive layout to ensure a seamless user experience across various devices and screen sizes.
4. Service Showcase: Highlighted consulting services, including educational guidance, counseling, and more.
5. Performance Optimization: Optimized the website for speed and performance to provide a smooth browsing experience.

Technologies Used
Frontend: React, Next.js, CSS (or Styled Components for styling)
Backend: Formspree API integration
Deployment: Deploy on Netlify.

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```


Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.
